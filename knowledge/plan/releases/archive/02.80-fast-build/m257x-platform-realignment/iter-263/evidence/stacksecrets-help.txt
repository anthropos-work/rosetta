stacksecrets - the secret-coverage harness + provisioning engine (values-blind).

usage:
  stacksecrets list       --dna <path>
  stacksecrets check      --dna <path> --from <DIR|ZIP> [--demo]
  stacksecrets introspect --dna <path> --stack-root <dir> [--write]
  stacksecrets diff       --dna <path> --stack-root <dir>
  stacksecrets provision  --dna <path> --from <DIR> --stack-root <dir> --stack <name> [--force] [--prod] [--dry-run]

  list       print the per-repo secret catalog (required / optional / waived + alias families).
  check      score a source against the DNA; exit 1 if critical coverage < 100%. (alias: measure)
             --demo: a demo stack — Clerkenstein-minted Clerk keys count as satisfied without the source.
  introspect rebuild the required-key set from the hybrid source (platform/.env_example +
             sentinel + frontends + curated); print it. --write refreshes the DNA's Source
             provenance line in place (NAMES-only metadata; the gene set stays hand-curated —
             gene drift is promoted manually via the diff verb).
  diff       reconcile the DNA against the hybrid declared set; exit 1 on an unlisted-required
             key (the keep-listed gate / anti-vacuous-green guard).
  provision  write each repo's target .env from the source (values-blind, alias-mapped per file).
             copy-if-absent by default; --force overwrites + permits the main dev stack (N=0).
             Defers to the injection override: NEVER re-arms the stripped prod DIRECTUS_TOKEN on a
             non-prod stack (--prod marks a prod target; default is non-prod). --dry-run plans only.

safety: no verb ever reads or echoes a secret VALUE — key NAMES + presence/shape only.
  provision MOVES secret bytes source->target .env (its job) but never logs/prints/errors on a value.
